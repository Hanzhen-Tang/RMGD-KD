# Presentation Assets

This folder collects PPT/framework-figure files generated for the paper.

- `scripts/`: generation scripts for editable PPTX files and PNG previews.
- `pptx/`: current editable PowerPoint outputs.
- `previews/`: current PNG previews corresponding to the editable PPTX files.
- `legacy/`: older intermediate PPTX/preview outputs kept for reference.

These files are not required for model training, testing, or result collection.
